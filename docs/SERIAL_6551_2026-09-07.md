# 6551 replacement and serial-port validation — 2026-09-07

The minimal byte-injection ACIA has been replaced with an adapted, pinned copy
of Gyorgy Szombathelyi's `gen_uart_mos_6551`. The Apple III bus adapter now
connects its serial pins and handshakes to MiSTer's HPS UART. The imported
implementation and license are recorded in [rtl/acia/README.md](../rtl/acia/README.md).

## Selection and corrections

A reproducible nine-check comparison (`sim/serial/compare_candidates.sh`) found
one failure in the selected upstream implementation and five in Apple II
MiSTer's older `glb6551`. Both lack transmit break; the older core additionally
fails control/parity preservation on programmed reset, status-read receive IRQ
acknowledgment, and DSR transition IRQs. This is a focused comparison, not a
complete certification of either upstream implementation.

Local corrections cover those behaviors plus selected-word parity, stop-bit
lengths and queued frame spacing, receive errors and overrun, false-start
rejection, modem gating, and the separate external receive-clock input. The
motherboard's grounded RxC input is respected. The adapter uses a fractional
1.8432 MHz clock enable in the existing 14.318182 MHz domain and synchronizes
incoming serial and handshake signals.

The original ROM's ACIA self-test revealed a reset-variant distinction:
command/control must reset to `$00`. Adopting the SY6551 manual table's `$02`
command value makes the original ROM report an ACIA failure. The integration
preserves the Apple-compatible `$00` behavior used by the other compared cores
and MAME. See the imported-core notes for primary-source references.

## Quartus and MiSTer

Quartus Prime Lite 17.0.2 under CrossOver completed the full production build
with zero errors and 25 warnings. All reported constrained timing checks pass:
worst setup slack is +0.192 ns, worst hold slack +0.255 ns, and total negative
slack is zero. Utilization is 15,762 / 41,910 ALMs (38%) and 371 / 553 RAM blocks
(67%). The shared MiSTer constraints still report unconstrained paths; this is
not a claim that every external path has a timing constraint.

The exact RBF was copied to MiSTer and its SHA-256 matched locally and remotely:

```
cdd2d18ec5d33bbdfc75e506c8962e6c79ef9649ba90c4906485483e2dadf400
```

On the DE10-Nano, with `Serial CTS: Host RTS`, `mister_echo.py` passed
4,096 binary bytes at 19200 8N1,
including every byte value. Deasserting HPS RTS stopped FPGA transmission;
asserting it again delivered all 64 queued bytes in order. The path includes
the HPS UART, FPGA serial pins, 6551, real T65 interrupt handler and RAM queue.

The first CTS test exposed a diagnostic-software race: mainline reads of the
ACIA status register could acknowledge an RX interrupt before the T65 took it.
A simulation of the same stall reproduced lost data. The corrected diagnostic
reads status only in its IRQ handler and uses TX interrupts to drain a stalled
queue. Both simulation and hardware pass with the same production RBF.

The hardware boot check also identified a host-idle mismatch: a closed HPS UART
deasserts RTS, making the 6551's CTS input not ready and failing the ROM's ACIA
self-test. Holding host RTS asserted allows boot. The OSD therefore offers
`Serial CTS: Always ready` by default, matching the unplugged motherboard's
pulled-up RS-232 receiver input; `Host RTS` enables host-controlled flow.
In Host RTS mode, the host must assert RTS before the stock ROM tests the ACIA.

The final RBF also boots the stock ROM and a disposable raw SOS 1.3 disk to the
[System Utilities menu](serial/2026-09-07-mister-sos.png), with the default
`Always ready` setting and no UART program running. The screenshot uses a
temporary `direct_video=0` override to capture all 560 columns.

The verified image is installed at
`/media/fat/_Computer/Apple-III_20260907_serial.rbf`. The earlier dated RBF is
unchanged. MiSTer was returned to MENU, its original INI restored byte-for-byte,
temporary test configs/ROM/disk/core/scripts removed, and Zaparoo and UART
services left stopped as found. The Python test restores UART settings on exit.

## Remaining limits

MiSTer has no separate DCD input, so this integration asserts carrier. This is
the internal FPGA-to-HPS UART connection, not a physical RS-232 voltage-level
interface. Sub-bit interrupt edge timing, modem changes during a frame and
mid-frame echo/break transitions have not been compared with a physical 6551.
The motherboard baud source is represented at its nominal frequency rather
than reproducing the original divider's jitter.
